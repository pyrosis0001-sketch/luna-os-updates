# LUNA OS updates

The apt repository that installed LUNA OS systems update from
(Settings > 업데이트·복구). It holds the `luna-os` package: the LUNA shell,
apps and session. Packages and the index are signed with the LUNA OS update
key, whose public half ships in every LUNA OS image
(`/usr/share/keyrings/luna-os.gpg`).

This repository is written by a tool; do not edit it by hand.
